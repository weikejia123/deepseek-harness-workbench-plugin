## 功能描述

文件/目录右键菜单顶部新增两项：

- **复制相对路径**（Copy relative path）：节点的工作区相对路径
- **复制完整路径**（Copy full path）：工作区绝对根路径 + 相对路径拼接

复制成功后 toast 提示「已复制到剪贴板」。异步 Clipboard API 不可用时（非安全上下文 / 权限被拒）自动降级为隐藏 textarea + `document.execCommand('copy')` 兜底。

## 设计决策（Why）

- **`workspacePath` 可选 prop 链路**：完整路径需要工作区绝对根路径，故从 Workbench（`workspace?.path`）→ SideDock → FileTree 逐层透传；设计为 **optional**，既有消费方（不传时只显示相对路径复制、完整路径退化为相对路径）无需改动。
- **剪贴板降级**：`navigator.clipboard` 在非 HTTPS / iframe 权限受限时抛错，须有 `execCommand` 兜底保证功能可用。
- **菜单位置**：置于菜单最顶部（打开/展开之前），符合「高频复制操作优先」的交互直觉；仅对文件/目录节点（`entry`）显示，根节点（`root` scope）不显示。
- **不带 lib**：同 PR #9，构建产物噪声问题，PR 描述已注明维护者合并时自行 build。
