# 001 文件树交互增强 — 设计实现报告

> 功能大类：文件树（刷新 / 复制路径 / 拖拽到消息框）
> 文档版本：V2-20260818（已实现并通过构建/测试）

## 元信息

| 项 | 值 |
|----|----|
| 插件 | deepseek-harness-workbench-plugin（wkj-dev） |
| 基线版本 | 0.1.17 |
| 需求来源 | 二开需求 2/3/4：文件树整体刷新按钮；右键菜单复制路径；拖拽节点到消息框追加路径 |

## 需求要点

1. 文件树顶部工具条加入**整体目录刷新**按钮，点击后刷新文件树。
2. 文件树节点右键菜单**顶部**加入「复制相对路径」「复制完整路径」两项，其后是菜单分隔线（避免点错下面分类中的菜单）。
3. 文件树节点**拖动到会话消息框**后，在消息文本**末尾**追加**双引号包围的文件完整路径**。

## 设计决策（Why）

### D1. 刷新按钮（功能 1）

- **位置**：`FileTree` 头部工具条 `headRow`（title 之后、外置编辑器按钮之前），复用已有 `IconRefresh` 图标。
- **行为**：`refreshAll()` 重新加载**根目录 + 所有已加载分支**（`Object.keys(branches)`），**保留展开状态**（`openDirs` 不清空），只是重拉目录列表。与现有 `reloadDirs` 复用 `load()`，实现一致、改动最小。
- **为什么不全量清空重建**：`setBranches({})` 会让所有展开目录闪成 loading，且丢失已展开状态；按需重载已加载目录即可达到"看到外部改动"的目的（外部新增的目录在根目录重载后出现）。

### D2. 复制路径菜单（功能 2）

- **位置**：`TreeContextMenu` 菜单**最顶部**（entry 节点右键时），两项复制 + 分隔线，然后才是原有「打开」等菜单，避免误点。
- **路径语义**：
  - 相对路径 = 节点 `entry.path`（工作区相对路径，`git` 语义）。
  - 完整路径 = 工作区绝对路径 + `/` + 相对路径。工作区绝对路径来自 `workspace.path`（`Workbench` 已有 `workspace?.path`，需新增 prop 逐层传至 `FileTree` / `TreeContextMenu`）。
- **复制实现**：优先 `navigator.clipboard.writeText`；失败回退隐藏 `textarea` + `document.execCommand('copy')`。成功后 `showInfo` 提示。
- **root 空白区右键**不显示这两项（无目标文件）。

### D3. 拖拽到消息框（功能 3）

- **拖拽数据**：`FileTree.handleDragStart` 已写入 `dataTransfer.setData('application/x-dsh-path', path)`，保留该自定义 MIME（作用域隔离，避免与系统文件拖拽冲突）。
- **落点监听**：composer（消息输入框）是 dsh 官方 UI（`conversation.composer.bar`，DOM 为 `[data-composer-seat]` 内的 `<textarea>`），不在插件组件树内，无法用 React `onDrop`。因此**在 `WorkbenchInner` 挂载 window 级捕获阶段 `dragover`/`drop` 监听**，按 `event.target.closest('[data-composer-seat]')` 判定落点。
- **追加格式**：`"完整路径"`（用户要求双引号包围）。当前文本末尾非空白时先补一个空格再追加，避免粘连。
- **React 受控更新**：直接改 `textarea.value` 不会更新 React 状态，须用原生 value setter 写入后派发 `InputEvent('input', { bubbles: true, inputType: 'insertText' })`，与 dsh `InputBar` 的受控 onChange 联动；随后 `focus()` 并移动光标到末尾。
- **不干预文件树内部拖拽**：文件树内部移动/粘贴是 `application/x-dsh-path` + 树内 drop 目标，监听器只对 `[data-composer-seat]` 内的 target 生效；树内 drop 由 `FileTree` 自己的 handler 处理。
- **卸载清理**：effect cleanup 移除全部监听。
