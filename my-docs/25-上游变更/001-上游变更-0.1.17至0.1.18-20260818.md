## 提交详情

### 1. `618fa48` feat(external-open): WSL 支持与路径处理增强

`src/host/external-open.ts`（+127 行）是本提交核心：

- **WSL 检测** `detectWsl(platform, env)`：仅 linux 平台，依据 `WSL_DISTRO_NAME` / `WSL_INTEROP` / `WSLENV` 环境变量判断（注释明确不用内核 osrelease，避免容器误判）。
- **WSL → Windows 路径转换** `wslToWindowsPath(abs, distro)`：
  - `/mnt/c/...` → `C:\...`（盘符大写、斜杠转反斜杠）
  - 非 /mnt 路径且知道发行版 → `\\wsl.localhost\<distro>\...`
- **WSL 下文件管理器**：新增 `WSL_EXPLORER_PATHS`（`/mnt/c/Windows/explorer.exe`、`/mnt/c/WINDOWS/explorer.exe`），reveal 优先 explorer.exe；缺失时回退 `xdg-open`。
- **`captureOutput`**：子进程 stdout/stderr 捕获工具（8s 超时）。
- `src/shared/errors.ts`：错误分类微调；`tests/external-open.spec.ts` +84 行（WSL 相关用例：explorer.exe 路径、非零退出回退、explorer 缺失回退等）。

> ⚠️ 本机环境说明：该提交的新增测试用例同样受本机 macOS TMPDIR 符号链接影响（external-open 文件在 macOS 上 realpath 判定逃逸），属环境固有失败，与代码无关。

### 2. `a672822` fix(client): Windows/Linux 文件管理器提示澄清 + 状态栏编辑器开关

- **GitSidebar 禁用状态细化**：
  - 新增 `disabledReason` prop：禁用按钮（restore / fileAction / 批量操作）的 label 与 title 显示具体原因（远程同步中 / 忙 / 分离 HEAD / 无 remote / 落后等）。
  - **busy 锁与 remote 锁分离**：`remoteLock.current` 独立于 `busyLock`，远程同步期间写操作禁用；`BUSY` 错误不再覆盖界面（`if (result.code !== 'BUSY') setError(...)`）。
  - 统一 `writeBlockReason`（remoteSyncing → `panel.checkingRemote`，busy → `action.disabledBusy`）。
- **StatusBar 编辑器状态栏 chrome 开关**：
  - `StatusBar` 新增 `editorOpen` prop（默认 true）；`showEditorStatusChrome(editorOpen)` 决定是否渲染标签条、溢出三角、键位模式菜单——**编辑器折叠成 rail 时隐藏这些状态栏内容**。
  - 编辑器关闭时自动收起模式菜单。
  - `Workbench.tsx` 传入 `editorOpen={editorOpen}`（该行与二开改动自动合并，无冲突）。
- **`remotePulse` 动画**：Git 侧栏远程同步时显示斜纹滚动指示条（`prefers-reduced-motion` 时降级为静态）。
- `lib/index.js` / `lib/client.js`：上游重建产物。

### 3. `40dfd59` refactor(client): 提交图布局逻辑重构

- **graph-lanes.ts 布局重写**：
  - 新增 `GraphLaneOptions.headHash`：**HEAD 提交的第一父链固定画在第 0 列直线**。
  - 经典 git-graph 规则落地：第一父链 lane 0；其余分支只往右侧开新列、在汇合处拐回；第一父提交继续走当前列。
  - `firstParentLine()` 计算 HEAD 链、`reserveLeft` 预留列、`allocLane` 分配算法。
- **graph-rail.ts**：rail 对齐调整（标题紧随 rails）。
- **GitGraph.tsx**：向 `layoutGraphLanes` 传入 `headHash`。
- **GitSidebar.module.css**：CSS 类映射调整。
- `tests/graph-lanes.spec.ts` / `tests/graph-rail.spec.ts`：用例随算法更新。
