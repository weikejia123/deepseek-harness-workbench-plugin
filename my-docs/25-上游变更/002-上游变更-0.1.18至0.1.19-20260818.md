### 2. 新增运行时依赖与服务

- `package.json` dsh.client.inject 增加 `@deepseek-ai/dsh-client-ui-input-trigger`；
- `src/client/index.ts`：`inject` 增加 `'inputTriggers'`，apply 中调用 `installUltraSlashClient(ctx)`。

### 3. 工作台侧栏新增「/」（插件命令）标签

- `WORKBENCH_SIDE_TABS` 增加 `'slash'`；
- `SideDock.tsx` / `Workbench.tsx`（rail 折叠栏）新增 `IconSlash` 按钮与 `SlashPanel` 分支；
- `icons.tsx` 新增 `IconSlash`；`locales.ts` 新增 `ide.slash`（zh「插件命令」/ en）。

### 4. 开发脚本清理旧包

- `devops/dev.sh`：安装前自动移除 profile 中残留的独立 `deepseek-harness-ultra-slash` 包（防止与并入后的本插件抢同一套 `/` 命令与 locale，导致「ultra-slash already has locale zh」整包加载失败）。

### 5. 其他

- README.md / README.zh-CN.md 更新（123 / 149 行）；新增截图 `docs/img/screen_shot_7.png`；
